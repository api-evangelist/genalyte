# Genalyte

> Genalyte, Inc. is a San Diego, California in-vitro diagnostics company building point-of-care
> blood testing systems on silicon photonic microring resonator technology. Its Merlin analyzer —
> successor to the Maverick Diagnostic System — runs hematology, chemistry and immunoassay panels
> from small whole-blood or serum volumes and returns results in roughly 20–30 minutes, with a
> cloud verification layer (marketed as CloudLab) that routes results into electronic medical
> record systems.

**Genalyte publishes no public API.** As of 2026-08-04 there is no developer portal, no API
documentation, no OpenAPI/AsyncAPI/GraphQL specification, no SDK, no MCP server, and no A2A agent
card on any Genalyte host. The `api.genalyte.com`, `cloudlab.genalyte.com` and `lab.genalyte.com`
hostnames exist in DNS but are dangling CNAMEs that resolve to no address. EMR integration is
described in marketing material but no interface specification is published.
